Propuesta v2: Motor de Intervención con Aprendizaje

Actualización del objetivo, arquitectura ampliada, y feedback loop para el Hackathon 2026.

Principios Invariantes:
1. La IA conversa; el banco decide.
2. El tono de una conversación describe la conversación, NO a la persona. Nunca se convierte en un atributo fijo del cliente ni altera su score financiero.

🎯 1. Objetivo Ampliado (Lo que debemos lograr)

  1. Detectar señales financieras tempranas antes del vencimiento.
  2. Determinar la situación del cliente en el ciclo actual.
  3. Aprender de patrones para decidir por qué canal y cuándo intervenir (con *fallback* a llamadas si no hay datos).
  4. Conversar empáticamente para descubrir la barrera real.
  5. Presentar únicamente alternativas autorizadas (ej. calendario, ahorro gradual).
  6. Registrar métricas por conversación (barrera, tono, turnos, resolución).
  7. Exponer un Dashboard Administrativo con el historial, métricas y retroalimentación hacia el motor de decisión.

🔄 4. El Ciclo de Aprendizaje (Feedback Loop)

El aprendizaje del MVP no es una "caja negra". Es tabular y auditable. Se creará una tabla nba_priority_table que cruza:

[Situación] + [Barrera] + [Canal] + [Alternativa] = Success Rate

El Next Best Action (NBA) ordenará las alternativas que ofrezca el LLM usando esta tabla, poniendo primero aquellas que históricamente tienen mayor éxito (con suavizado Bayesiano).

⚠️ Prohibido: Retroalimentar el score financiero con las interacciones del LLM (ej. un cliente enojado no significa que sea más riesgoso financieramente).

📊 5. El Dashboard de Administración (Requerimiento para Camila)

  • Vista 1 (Cartera): Distribución de las situaciones, porcentaje de NO_CONTACT, y lista de clientes a contactar.
  • Vista 2 (Conversaciones): Historial y transcripciones con filtros por tono, barrera y resultado. Detalle de si el LLM tuvo alucinaciones.
  • Vista 3 (Interacción): Tasa de aceptación por canal y barrera. Promedio de turnos requeridos para cerrar.
  • Vista 4 (Modelos): Distribución del *Anomaly Score* y métricas (sintéticas) de Regresión Logística. Rendimiento de los canales y horarios.
  • Vista 5 (Aprendizaje): Botón para "recalcular" el *Feedback Loop* mostrando cómo se reordenan las alternativas en el catálogo del NBA.
