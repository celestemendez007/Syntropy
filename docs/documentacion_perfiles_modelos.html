🔄 3. El Flujo End-to-End (Cómo funciona el sistema)

Regla Central: "ML detecta. Las reglas deciden. El LLM comprende. El backend valida."

1. Datos & ML Datos sintéticos → Isolation Forest + Logistic Regression extraen el Score de anomalía y riesgo.
2. Decisión (NBA) El Next Best Action decide por reglas deterministas si intervenir, en qué canal, momento y objetivo.
3. Nudge (UI) La Banca Móvil simulada muestra el Nudge preventivo (Tarjeta) solo al cliente que lo necesita.
4. Chatbot (Agente) Agente por estados (Start→Understand→Confirm) comprende la situación del cliente con skills limitados.
5. Autoridad Financiera El Policy Engine + Tools validan que la IA no prometa lo prohibido (fechas exageradas, montos mínimos, waivers).
6. Resolución Cliente selecciona, rechaza o solicita a un humano, generando un cierre explícito y verificable.
7. Memoria & Auditoría El Dashboard interno registra la trazabilidad, logs de la conversación, canal y memoria para el futuro.

🏆 4. Productos Esperados (Entregables del MVP)

📱 Banca Móvil (Mock)

Interfaz que simule la aplicación del banco, integrando el Nudge preventivo ("Revisar mi pago") con cero fricción.

💬 Asistente de Texto Inteligente

Chat funcional empático, controlado por el motor de estados, que no alucina información financiera y comprende barreras reales.

🛡️ Motor de Políticas / NBA

Lógica determinista invisible al usuario pero infalible, que entrega un menú de opciones 100% autorizadas y seguras.

📊 Dashboard de Auditoría

Panel interno para el banco que muestra el riesgo, métricas, historial de la conversación, eficacia del contacto y trazabilidad total.
